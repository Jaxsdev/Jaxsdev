# 📌 Other Projects

### 🏙️ QHALI

Plataforma inteligente para reportes ciudadanos que combina
**Artificial Intelligence, Geospatial Data y Crowdsourced Validation**.

El sistema utiliza IA para clasificar y priorizar reportes, mientras
que las reglas geoespaciales permiten validar su ubicación y detectar
posibles duplicados.

**Stack:** Next.js · FastAPI · PostgreSQL · Supabase · AI · PostGIS

---

### 🗺️ Wanka Maps

Plataforma orientada a recopilar y visualizar rutas de transporte
público mediante información geográfica.

El proyecto busca facilitar la construcción colaborativa de información
sobre movilidad urbana.

**Stack:** JavaScript · Maps · Geolocation · APIs

---

### 🏗️ Construction ERP

Sistema empresarial diseñado para centralizar diferentes procesos de
una empresa constructora.

La propuesta contempla módulos para **Management, Administration,
Accounting, Human Resources y Logistics**, utilizando una arquitectura
modular.

**Focus:** Enterprise Systems · Software Architecture · Databases

---

### ⛏️ MINEX

Plataforma de **AI-Powered Vocational Guidance** desarrollada como
propuesta tecnológica para el sector minero.

El proyecto busca utilizar Inteligencia Artificial para orientar a los
usuarios en la identificación de habilidades, intereses y posibles
rutas profesionales.

**Stack:** AI · Supabase · Vercel
